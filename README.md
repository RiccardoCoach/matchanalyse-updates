# Matchanalyse – öffentlicher Updatekanal

Dieses Repository dient ausschließlich der automatischen Aktualisierung der Windows-App **Matchanalyse**.

Veröffentlicht werden nur:

- signierte bzw. geprüfte Windows-Installer,
- die Updatebeschreibung `latest.json`,
- SHA-256-Prüfsummen.

Hier werden **kein Quellcode** und **keine Nutzerdaten** gespeichert. Spiele, Videos, Szenen, Zeichnungen, Einstellungen und Vereinsdaten verbleiben lokal auf dem jeweiligen Computer. Der Quellcode der Anwendung bleibt in einem privaten Repository.

Die App lädt Aktualisierungen nur von diesem öffentlichen Kanal und prüft vor der Installation Dateigröße und SHA-256-Prüfsumme.
